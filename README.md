# 🌱 نمو — المستشار المالي الذكي

مساعد لاتخاذ القرار المالي يساعدك على فهم العقود، ومحاكاة أثر قراراتك المستقبلية، وربطها بأهدافك المالية الشخصية.

مبني بالشراكة مع **مصرف الإنماء** لهاكاثون أمد.

---

## 🚀 كيف تشغّل المشروع

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إضافة مفتاح Anthropic API
```bash
# على Mac/Linux
export ANTHROPIC_API_KEY="sk-ant-..."

# على Windows
set ANTHROPIC_API_KEY=sk-ant-...
```

### 3. تشغيل السيرفر
```bash
python app.py
```

### 4. افتح المتصفح
```
http://localhost:5000
```

## ✨ المميزات

- **تحليل الوضع المالي** — دخل، مصروفات، مدخرات، نسبة الادخار
- **استشارة القروض** — احتساب الأقساط وتقييم الأهلية وفق معايير ساما
- **سيناريوهات ماذا لو** — محاكاة أثر القرارات المستقبلية
- **خطة أ وخطة ب** — بدائل عملية لكل موقف
- **تحليل الوثائق المالية** — رفع صورة وثيقة للتحليل الفوري
- **مؤشر الضغط المالي** — تنبيه مبكر قبل تفاقم الوضع
