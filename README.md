# 🌱 نمو — المستشار المالي الذكي

> مساعد ذكي لاتخاذ القرار المالي، يساعدك على فهم وضعك المالي، ومحاكاة أثر قراراتك المستقبلية، وربطها بأهدافك المالية الشخصية.

مبني بالشراكة مع **مصرف الإنماء** ضمن فعاليات **هاكاثون أمد**.

🔗 **جرّب المشروع مباشرة:** [https://numuw-sk8c.onrender.com](https://numuw-sk8c.onrender.com)

---

## 💡 الفكرة

كثير من الأشخاص يتخذون قرارات مالية مهمة (قرض، شراء، ادخار) بدون فهم كامل لأثرها المستقبلي على وضعهم المالي. **نمو** يحل هذه المشكلة عبر:

- تحليل الوضع المالي الحالي للمستخدم بلغة بسيطة وواضحة
- محاكاة سيناريوهات "ماذا لو" قبل اتخاذ القرار
- تقييم أهلية القروض وفق معايير ساما الرسمية
- تقديم خطط بديلة عملية (خطة أ / خطة ب) بدل الاكتفاء بقول "لا"

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 📊 **تحليل الوضع المالي** | دخل، مصروفات، مدخرات، ونسبة الادخار في لوحة تحكم بصرية |
| 🏦 **استشارة القروض** | احتساب الأقساط الشهرية وتقييم الأهلية وفق معايير ساما (33% حد أقصى) |
| 🔮 **سيناريوهات ماذا لو** | محاكاة أثر القرارات المالية المستقبلية قبل اتخاذها |
| 📋 **خطة أ وخطة ب** | بدائل عملية وواقعية مع توضيح التنازلات (Trade-offs) |
| 🖼️ **تحليل الوثائق المالية** | رفع صورة وثيقة (كشف حساب، عقد) للتحليل الفوري |
| ⚠️ **مؤشر الضغط المالي** | تنبيه مبكر قبل تفاقم الوضع المالي |

## 🛠️ التقنيات المستخدمة

- **Backend:** Python, Flask
- **AI:** Anthropic Claude API (Claude Haiku 4.5)
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Data Visualization:** Chart.js
- **Deployment:** Render (Gunicorn)

## 🚀 كيف تشغّل المشروع محلياً

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إضافة مفتاح Anthropic API
أنشئي ملف باسم `env` في المجلد الرئيسي وضعي بداخله:
```
ANTHROPIC_API_KEY=sk-ant-...
```

أو عبر متغيرات البيئة مباشرة:
```bash
# على Mac/Linux
export ANTHROPIC_API_KEY="sk-ant-..."

# على Windows
set ANTHROPIC_API_KEY=sk-ant-...
```

### 3. تشغيل السيرفر
```bash
python app.py
```

### 4. افتحي المتصفح
```
http://localhost:5000
```
